# Portafolio QA | Juan Sebastián Garzón Méndez

## Sobre mí 👋

Soy Ingeniero Multimedia y QA Engineer graduado de TripleTen. Cuento con 8 años de experiencia en diseño y producción de contenidos interactivos para plataformas LMS, donde también realicé validaciones funcionales y pruebas de humo manuales para comprobar el correcto funcionamiento de contenidos digitales y paquetes SCORM.

Durante mi formación como QA Engineer desarrollé proyectos prácticos de pruebas funcionales en aplicaciones web, móviles y API, así como automatización de pruebas utilizando Python, Pytest y Selenium WebDriver.

Me interesa el aseguramiento de la calidad del software, la identificación y documentación de errores y la mejora de la experiencia del usuario. Busco continuar desarrollándome en testing funcional, pruebas de API, automatización y QA de videojuegos.

## Experiencia relacionada con QA 🏢

Mi experiencia en el sector multimedia me permitió trabajar con plataformas digitales, interfaces, simuladores y contenidos interactivos. Entre mis responsabilidades se encontraba verificar la navegación, los botones, los menús, los elementos multimedia y el funcionamiento general de los contenidos publicados en plataformas LMS.

Esta experiencia fortaleció mi atención al detalle, análisis de errores y capacidad para documentar problemas, habilidades que he complementado con mi formación y proyectos de QA.

## Proyectos de QA 🧪

### 1. Urban Grocers – Automatización de pruebas de API
**Sprint 8 | Python y Pytest**

Proyecto de automatización de pruebas para la API de Urban Grocers.

**Actividades realizadas:**
- Desarrollo de pruebas automatizadas para endpoints GET, POST, PUT y DELETE.
- Uso de Pytest para organizar y ejecutar los casos de prueba.
- Implementación de funciones reutilizables de aserción para validar respuestas HTTP.
- Organización del proyecto y documentación de su funcionamiento mediante un archivo README.

**Tecnologías:** Python, Pytest, PyCharm, Git y GitHub.

**Repositorio:** [qa-project-Urban-Grocers-app-es](https://github.com/juansebastiangarzon/qa-project-Urban-Grocers-app-es)

### 2. Urban Routes – Automatización de pruebas de interfaz de usuario
**Sprint 9 | Selenium WebDriver**

Proyecto de automatización del flujo de solicitud de taxi en la aplicación Urban Routes.

**Actividades realizadas:**
- Inspección de elementos HTML mediante Chrome DevTools.
- Construcción de localizadores CSS y XPath.
- Automatización del flujo de solicitud de taxi, incluyendo selección de tarifa, teléfono, tarjeta, mensaje al conductor y artículos adicionales.
- Aplicación del patrón Page Object Model (POM).
- Uso de esperas explícitas y condiciones esperadas para interactuar con los elementos de la interfaz.

**Tecnologías:** Python, Selenium WebDriver, PyCharm, Git y GitHub.

**Repositorio:** [qa-project-Urban-Routes-es](https://github.com/juansebastiangarzon/qa-project-Urban-Routes-es)

### 3. Urban Scooter – Proyecto final integrador
**Sprint 10 | Pruebas web, móviles y API**

Proyecto final de formación enfocado en la evaluación funcional de Urban Scooter en sus plataformas web, móvil y API.

**Actividades realizadas:**
- Análisis de requisitos funcionales para identificar las condiciones de prueba.
- Diseño y ejecución de listas de comprobación para las funcionalidades web, móviles y API.
- Documentación de los resultados mediante los estados APROBADO y NO APROBADO.
- Identificación, reproducción y documentación de errores en Jira.
- Vinculación de los informes de errores con los resultados de las pruebas.
- Preparación de la entrega final con evidencias y trazabilidad.

**Áreas de prueba:** Web Testing, Mobile Testing y API Testing.

**Documentación:** [Informe del proyecto Urban Scooter](docs/informe-final-pruebas-de-software.pdf)
